# Ylab University — Интенсив Java (II поток)
## Описание
Домашние задания от Ylab University по курсу "Интенсив Java (II поток)".

В качестве предметной области для изучения технологий Java требуется разработать продуктовый маркетплейс (Product Catalog Service).  
Каждое следующее домашнее задание является доработкой предыдущего согласно требованиям ТЗ.  

Таким образом, к концу интенсива было разработано полноценное многомодульное (multimodule Maven) приложение с использованием технологий Java Spring Framework.

## Стек технологий
- Java 17 / Java 25
- Maven (multimodule project)

### Web / Backend
- Spring Framework / Spring Boot
- Spring WebMVC
- Tomcat (встроенный контейнер сервлетов)
- Swagger / OpenAPI (документация REST API)
- Jackson (JSON-сериализация)
- Servlet API

### База данных
- PostgreSQL
- JDBC / HikariCP
- Flyway (миграции БД)

### Контейнеризация
- Docker

### Архитектура и утилиты
- AOP (Spring AOP)
- MapStruct

### Тестирование
- JUnit 5 / Mockito / Spring WebMVC Test
