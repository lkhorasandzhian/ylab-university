# Домашнее задание 1
Домашнее задание по теме "1. Вводная".

## 💡 Основные возможности

### 👤 Авторизация и регистрация
- Регистрация новых пользователей;
- Авторизация с проверкой пароля;
- Роль `ADMIN` имеет доступ к управлению каталогом.

### 📦 Управление товарами
- Добавление, изменение, удаление и просмотр товаров;
- Проверка корректности данных (валидация полей);
- Автоматическая генерация `UUID` для новых товаров.

### 🔍 Поиск и фильтрация
- По категории;
- По бренду;
- По диапазону цен включительно;
- По ключевому слову (в названии или описании).

### ⚡ Кэширование запросов
- Повторные запросы фильтрации и поиска выполняются быстрее;
- Используется собственная реализация LRU-кэша (`CacheService`).

### 🧾 Аудит действий
- Логирование всех действий пользователей (вход, выход, операции с товарами);
- Просмотр истории аудита доступен только администраторам.

### 💾 Сохранение данных
- Все данные сериализуются в каталог `serialize_data/` при завершении работы;
- Автоматическая загрузка при запуске программы.

---

## 🧠 Пример взаимодействия
Демонстрация работы программы находится в папке `console_output`.

## 🗃️ Структура хранения данных
Все данные приложения сохраняются в каталоге `serialize_data/`, который создаётся автоматически
при первом запуске программы. Каждый тип данных хранится в отдельном сериализованном файле.

Структура `serialize_data/`:  
- `products.dat`: "Список товаров (объекты Product)"
- `users.dat`: "Зарегистрированные пользователи (объекты User)"
- `audit.dat`: "Журнал действий пользователей (объекты AuditRecord)"

### Примечание:
При завершении работы данные автоматически сериализуются и сохраняются.
При следующем запуске приложения они загружаются обратно в память.


## 🚀 Запуск приложения
Через IDE (IntelliJ IDEA):
- Открыть проект как Maven.
- Убедиться, что установлена JDK версии 21 или выше.
- Запустить класс `ru.ylab.levon.Main` через конфигурацию Run.

Через консоль:  
- Выполнить сборку проекта:
команда: mvn clean package
- Запустить скомпилированный jar-файл:
команда: java -cp target/homework-1-1.0-SNAPSHOT.jar ru.ylab.levon.Main

### Примечание:
При первом запуске создаётся папка `serialize_data/`. В случае пустого списка пользователей автоматически создается пользователь с правами администратора (данные для входа: `admin / admin`) для авторизации.
